Provides predefined groups of MIME mappings that backfill extensions missing from the target framework's ASP.NET Core static-file defaults.

Media

Backfills web-media mappings that differ across the supported ASP.NET Core target frameworks.

Declaration
public static StaticFileAdditionalMappings Media { get; }
Property Value
Type Description
StaticFileAdditionalMappings
Remarks

On net8.0, this adds .avif as image/avif. ASP.NET Core 10 already provides that mapping, so the group is intentionally empty on net10.0.

WebApp

Backfills static-file mappings needed by legacy PWA/Blazor hosting that are still absent from the current ASP.NET Core defaults.

Declaration
public static StaticFileAdditionalMappings WebApp { get; }
Property Value
Type Description
StaticFileAdditionalMappings
Remarks

ASP.NET Core already maps .webmanifest and .wasm for the supported target frameworks, so this group currently adds only .br and .dat as application/octet-stream.
