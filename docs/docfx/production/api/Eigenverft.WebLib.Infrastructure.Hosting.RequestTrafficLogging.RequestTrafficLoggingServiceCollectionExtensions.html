Adds framework HTTP capture plus WebLib request-completion semantics for one structured traffic record per request.

Remarks

Request traffic logging intentionally owns the global ASP.NET Core HttpLoggingOptions used by this pipeline: it post-configures combined logging, the baseline logging fields, body limits, and header allowlists so that the interceptor can select the final per-request capture. Existing AddHttpLogging(...) configuration is therefore normalized to the A4 traffic-logging contract. Configure the shared capture through RequestTrafficLoggingOptions when A4 is enabled.
