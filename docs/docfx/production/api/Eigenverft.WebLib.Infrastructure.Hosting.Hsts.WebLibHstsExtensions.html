AddWebLibHsts(IServiceCollection)

Registers native HSTS services with the Eigenverft 180-day max-age baseline and binds the standard Hsts configuration section.

Remarks

Configuration is applied after the WebLib baseline. Native HstsOptions defaults, including excluded hosts, remain owned by ASP.NET Core. Middleware activation is intentionally handled separately by UseWebLibHsts(IApplicationBuilder).

UseWebLibHsts(IApplicationBuilder)

Adds ASP.NET Core's native HSTS middleware outside the Development environment.

Declaration
public static IApplicationBuilder UseWebLibHsts(this IApplicationBuilder app)
Parameters
Type Name Description
IApplicationBuilder app

The application builder.
Returns
Type Description
IApplicationBuilder

The same application builder.
Remarks

Place this early enough to wrap responses that may short-circuit later in the pipeline, such as rate-limit rejections and health probes. HTTP requests and excluded hosts continue to follow the native ASP.NET Core HSTS middleware semantics.
