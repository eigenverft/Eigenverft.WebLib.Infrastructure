Remarks

The server-wide limiter is intentionally opt-in. Its numeric defaults are zero so enabling it without explicit burst and sustained-rate values fails validation instead of silently imposing an arbitrary production limit. Its bounded queue is native OldestFirst FIFO arrival ordering, not per-client fairness.
