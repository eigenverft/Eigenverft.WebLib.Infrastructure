Class WebLibFloodProtectionOptions

Configures the WebLib convenience layer over ASP.NET Core rate limiting for generic request flood protection.

Remarks

The defaults are intentionally only a practical starting point. They are not universal security boundaries and should be load-tested and tuned for the consuming application and its expected traffic profile.

The primary limiter is a token bucket partitioned by the normalized client IP address. An optional global concurrency limiter can be enabled as an additional whole-application guard.
