Initial reusable ASP.NET Core SerilogRelay receiver API with endpoint-scoped bearer authentication and maximum batch-event limits, protocol validation, multi-application batch support, and a storage-neutral ISerilogRelayBatchHandler boundary. After validation, durable handler cancellation follows the host application lifetime rather than the client request lifetime. Receiver hardening additionally covers independent multi-endpoint options, null-event validation, JSON subtype and charset handling, client-disconnect durability, host-shutdown `503` semantics, and transactional rollback/reference coverage. Relay wire JSON deserialization is now isolated from global host `HttpJsonOptions` while retaining ASP.NET Web-compatible defaults.
